# Calling a selected CE skill

Resolve the selected Compound Engineering `SKILL.md`, read its instructions,
execute the applicable procedure, and return to the requested delivery
boundary. Reading a file alone does not execute the workflow; no native
skill-call primitive or extra procedure-frame receipt is assumed.

A CE stage can run in the current session or a useful native subagent. It does
not require a specially named LFG carrier, hook admission, skill digest, or
route receipt. Choose the child's model and reasoning effort deliberately,
using a compatible history fork, just as for other assignments.

LFG owns its internal stages, including its CE review and babysitting loop.
Do not duplicate those stages around it. Deliver consumes its result and
continues the authorized merge/post-merge tail. For an existing PR outside LFG,
CE's selected PR workflow remains the single review and CI owner.

Follow explicit user and repository scope or stop instructions. A plan-only or
local-only request remains bounded even when a loaded skill has a broader
default. Load this reference only when cross-skill invocation needs explaining.
