# Fleet

The fleet surface keeps machines visible, trusted, and converged through a readable store and host-owned evidence.

- [Store](/fleet/store/) — the layered desired-state repository.
- [Convergence](/fleet/convergence/) — one edit from source to applied state.
- [Trust](/fleet/trust/) — roster, signing ratchet, enrollment, and revocation.
- [Operating](/fleet/operating/) — commands, cadence, doctor, and journals.
- [Config](/fleet/config/) — the local machine and capability schema.
- [Why jj](/fleet/why-jj/) — the version-control properties that support the store.

[Desired state](/desired-state/) gives the same model a standalone reader path.
