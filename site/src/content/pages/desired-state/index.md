# Desired state

Declare the machine surface you want, test it through a canary, and require evidence that each host arrived there. This model turns infrastructure intent into a readable operating contract that agents and operators can trust. [Roundhouse](/roundhouse/) supplies the standalone store, convergence loop, cadence, and trust controls that make it real.

- [Declare it in a fleet](/roundhouse/store/) — place the fold inside the store and its trust path.
- [Scale the model](/desired-state/scaling/) — understand the first evidence breakpoint and the next levers.

Start with [declare desired state](/what-it-does/declare-desired-state/) for the shortest value path. The [Roundhouse repository](https://github.com/novotnyllc/roundhouse) provides the implementation and release evidence behind it.
