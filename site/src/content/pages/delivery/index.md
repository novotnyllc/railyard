# Delivery

Delivery turns a request into a bounded, reviewed, merged, and observable result.

- [Lifecycle](/delivery/lifecycle/) — one request from intent to proof.
- [Routing](/delivery/routing/) — model, effort, budget, privacy, and transport.
- [Gates](/delivery/gates/) — review settlement, merge authority, and post-merge proof.
- [Audit](/delivery/audit/) — the run record and retrospective that explain how the result arrived.

The [ship a change scenario](/what-it-does/ship-a-change/) is the shortest introduction.
